# Schema 目录

V0 先冻结字段语义和示例，不把 JSON Schema 写得过早复杂。

- `work.schema.example.json`：作品结构示意；
- `person.schema.example.json`：人物结构示意；
- `evidence.schema.example.json`：Evidence 结构示意。

V1 开发时再基于真实 TypeScript Domain Model 生成或维护正式 JSON Schema，并加入自动校验测试。
- `commit-plan.schema.example.json`：V1-06 正式写入前的 Commit Plan 示例。
- `commit-receipt.schema.example.json`：V1-06 正式归档后的 Commit Receipt 示例。
