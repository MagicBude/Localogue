# 职业事件词表

| ID | 日本語 | 简体中文 | English |
|---|---|---|---|
| `debut` | デビュー | 出道 | Debut |
| `retirement` | 引退 | 引退 | Retirement |
| `return` | 復帰 | 复出 | Return |
| `hiatus_start` | 活動休止 | 开始休业 | Hiatus Start |
| `hiatus_end` | 活動再開 | 恢复活动 | Hiatus End |
| `name_change` | 改名 | 改名 | Name Change |
| `agency_change` | 所属変更 | 所属变更 | Agency Change |
| `other` | その他 | 其他 | Other |

职业事件允许日期精度不足，例如只有年份或年月。
