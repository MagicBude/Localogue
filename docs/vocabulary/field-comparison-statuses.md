# 字段比较状态

| ID | 日本語 | 简体中文 | English | 说明 |
|---|---|---|---|---|
| `same` | 一致 | 一致 | Same | Evidence 与 Library 相同 |
| `different` | 異なる | 不同 | Different | 两侧都有值但不同 |
| `evidence_only` | Evidence のみ | 仅 Evidence 有值 | Evidence only | 可作为字段补全候选 |
| `library_only` | Library のみ | 仅资料库有值 | Library only | Evidence 缺失不代表应删除 Library 值 |

机器可读版本：`resources/vocabularies/field-comparison-statuses.json`。
