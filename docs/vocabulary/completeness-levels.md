# 资料完整度等级

| ID | 日本語 | 简体中文 | English | 分数下限 |
|---|---|---|---|---:|
| `complete` | 完全 | 完整 | Complete | 90 |
| `good` | 良好 | 良好 | Good | 75 |
| `needs_attention` | 要確認 | 需要补全 | Needs attention | 50 |
| `incomplete` | 不完全 | 资料不足 | Incomplete | 0 |

> 完整度只说明“字段是否丰富”，不说明这些字段一定正确。真实性仍由 Evidence、Provenance 与人工 Review 保证。
