# 核心术语表

| 英文术语 | 中文 | 日本語 | 在 Localogue 中的含义 |
|---|---|---|---|
| Canonical Library | 规范资料库 | 正規ライブラリ | 当前被 Localogue 接受为正式结果的数据 |
| Evidence | 来源证据 | エビデンス | 某次导入或外部来源提供的原始信息 |
| Curation | 资料治理 / 策展 | キュレーション | 审核、匹配、去重、修正和维护资料 |
| Exploration | 资料探索 | 探索 | 浏览、筛选、排序、时间线和关系跳转 |
| Work | 作品 | 作品 | 逻辑作品实体，与视频文件分离 |
| Person | 人物 | 人物 | 演员、导演等统一人物实体 |
| Maker | 厂商 | メーカー | 公司 / 制作发行体系中的厂商实体 |
| Label | 厂牌 | レーベル | Maker 下的品牌或作品线 |
| Series | 系列 | シリーズ | 一组有共同企划关系的作品 |
| Work Type | 作品类型 | 作品タイプ | 单体、共演、VR、写真影像、合辑等形式 |
| Genre | 分类 / 题材 | ジャンル | 作品内容或行业分类 |
| Tag | 标签 | タグ | 用户自己的整理标签 |
| Asset | 资源 | アセット | 封面、海报、截图、人物图等文件 |
| MediaFile | 媒体文件 | メディアファイル | 本地真实视频文件 |
| Importer | 导入器 | インポーター | 把某种输入格式转换成统一导入模型 |
| Connector | 外部连接器 | コネクター | V3 可选的在线数据来源适配器 |
| Review | 审核 | レビュー | 在正式写入前比较与确认数据 |
| Facet | 筛选维度 | ファセット | 演员、年份、Maker、Genre 等可组合条件 |
| Provenance | 来源追踪 | 出典追跡 | 记录字段来源和选择原因 |
