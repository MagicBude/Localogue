# 作品类型词表

Work Type 描述作品的形态或发行形式。一个作品允许多个 Work Type。

| ID | 日本語 | 简体中文 | English | 说明 |
|---|---|---|---|---|
| `solo` | 単体作品 | 单体作品 | Solo | 主要围绕单一主演人物的作品 |
| `co_starring` | 共演作品 | 共演作品 | Co-starring | 多位主要人物共同出演 |
| `vr` | VR作品 | VR作品 | VR | VR 形式作品 |
| `image_video` | イメージビデオ | 写真影像 | Image Video | 以形象、写真影像为主要定位 |
| `compilation` | 総集編 | 合辑 | Compilation | 已有内容整理形成的合集 |
| `omnibus` | オムニバス | 单元合集 | Omnibus | 多个相对独立单元组合 |
| `best_of` | ベスト | 精选集 | Best Of | 精选性质的汇编作品 |
| `other` | その他 | 其他 | Other | 无法归入已知类型 |

## 说明

Work Type 与 Genre 不同。例如 `vr` 是形式，`uniform` 属于内容分类。
