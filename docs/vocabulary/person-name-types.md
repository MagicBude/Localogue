# 人物姓名类型词表

| ID | 日本語 | 简体中文 | English | 用途 |
|---|---|---|---|---|
| `primary` | 正式名 | 正式名 | Primary Name | 当前主要正式名称 |
| `localized` | 翻訳名 | 本地化名称 | Localized Name | 中文等本地化映射 |
| `romanized` | ローマ字 | 罗马字名 | Romanized Name | 拉丁字母转写 |
| `stage_name` | 芸名 | 艺名 | Stage Name | 艺名 |
| `alias` | 別名 | 别名 | Alias | 常见别名 |
| `former_name` | 旧名 | 旧艺名 / 曾用名 | Former Name | 历史使用名称 |
| `alternate` | 別表記 | 其他写法 | Alternate Name | 字体、空格、写法差异等 |

每个姓名条目还应带语言代码、可选的有效时间范围和来源。
