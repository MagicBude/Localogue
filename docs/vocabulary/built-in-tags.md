# 内置 Tag 建议

Tag 主要由用户自定义，但 Localogue 可以提供少量系统建议标签。

| ID | 日本語 | 简体中文 | English |
|---|---|---|---|
| `favorite` | お気に入り | 收藏 | Favorite |
| `recommended` | おすすめ | 推荐 | Recommended |
| `watch_later` | 後で見る | 待观看 | Watch Later |
| `needs_metadata` | 情報補完待ち | 待补资料 | Needs Metadata |
| `needs_cover` | カバー補完待ち | 待补封面 | Needs Cover |
| `needs_review` | 要確認 | 待审核 | Needs Review |

这些只是预置建议。用户自定义 Tag 不要求三语齐全。
