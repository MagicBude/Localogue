# 资料治理总览

资料治理（Curation）与资料探索（Exploration）同等重要。

Localogue 的“整理”区域至少覆盖：

- 待审核导入；
- 疑似重复作品；
- 疑似重复人物；
- 未匹配人物；
- 未映射 Genre；
- 字段冲突；
- 缺少封面；
- 缺少核心资料；
- 找不到本地媒体文件；
- 资源文件重复；
- 资料完整度不足。

V1 可以先实现规则驱动，不依赖 AI。AI 未来只能作为辅助判断层，不能绕过 Review。

## V1-08：从“审核导入”扩展到“日常治理”

新增 `/curation` 作为日常维护入口：

- 完整度不足 Work；
- 完整度不足 Person；
- Evidence 生命周期批量处理；
- DuplicateCandidate；
- 人物手工补全入口。

治理队列不修改 Canonical 真相，它只告诉用户“哪里值得处理”。
