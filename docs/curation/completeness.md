# 资料完整度

资料完整度用于帮助用户发现“哪些资料还需要整理”，不用于评价作品本身。

## V1 建议核心检查项

| 字段 | 建议权重 |
|---|---:|
| 番号 | 必需 |
| 日文原始标题 | 必需 |
| 发行日期 | 高 |
| 时长 | 高 |
| 演员关系 | 高 |
| Maker | 中 |
| Label | 中 |
| Series | 中 |
| Work Type | 高 |
| Genre | 中 |
| 主封面 | 高 |
| 简介 | 低 |
| 本地文件 | 不计入元数据完整度 |

## 状态

- `complete`：主要资料完整；
- `partial`：有可继续补充字段；
- `minimal`：只有少量核心字段；
- `needs_review`：存在冲突或待确认内容。

## 注意

“没有本地媒体文件”不是资料错误。Work 和 MediaFile 已明确分离。
