# 筛选字段

## V1 作品筛选

| 维度 | 示例 |
|---|---|
| 演员 | Person ID |
| 导演 | Person ID + role=director |
| Maker | Maker ID |
| Label | Label ID |
| Series | Series ID |
| 年份 | 2026 |
| 月份 | 2026-08 |
| 日期范围 | 2024-01-01 ~ 2026-12-31 |
| 时长 | 90 ~ 150 分钟 |
| Work Type | solo / vr 等 |
| Genre | Canonical Genre ID |
| Tag | 用户 Tag |
| 本地文件 | 有 / 无 |
| 封面 | 有 / 无 |
| 完整度 | 完整 / 缺失字段 |
| 添加时间 | 最近添加 |
| 更新时间 | 最近修改 |

## 人物筛选

人物库未来至少支持：

- 当前状态；
- 出道年份；
- 引退年份；
- 出生年份；
- 出生地；
- 作品数量区间；
- 是否有头像；
- 资料完整度。
