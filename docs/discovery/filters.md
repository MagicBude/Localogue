## 人物筛选

人物库未来至少支持：

- 当前状态；
- 出道年份；
- 引退年份；
- 出生年份；
- 出生地；
- 罩杯；
- 是否有人物图片、出生日期、身高、三围和简介；
- 作品数量区间；
- 是否有头像；
- 资料完整度。

当前共享 `PersonQuery` 已实现姓名、状态、三个职业 / 出生年份、出生地、罩杯、身高区间，以及人物图片、出生日期、身高、三围、简介的有无筛选。作品数量需要 Work 关系聚合，资料完整度属于可重算治理信号，仍需在后续统一查询上下文中实现，不能由 Desktop 页面临时拼接第二套语义。

Desktop 的状态、年份与罩杯选项显示 self-excluding 结果数量：计算某一维度时临时忽略该维度自身，保留其他已选条件。这与作品 Facet 的语义一致，避免用户把“当前已选后只剩一个选项”误认为资料库只有一个值。
