# 已选筛选条件 Chips

## 目的

多维筛选一旦同时选择演员、年份、厂商、类型和 Genre，用户很容易忘记当前到底启用了哪些条件。

因此作品结果区域顶部显示“已选筛选”：

```text
演员：A ×
年份：2026 ×
厂商：B ×
作品类型：单体 ×
```

每个 Chip 都是一个 URL 链接。

点击某一个 Chip 的 `×`：

- 只删除这一项；
- 保留其它筛选；
- 保留排序和视图；
- 删除当前页码并回到第 1 页。

## 为什么它不是 React 本地状态

因为真正的筛选状态已经存在 URL 中。

Chips 只是 URL 状态的一种“可视化”。

这保证：

```text
左侧筛选器
URL
已选 Chips
查询结果
```

四者来自同一个状态源，不会互相不同步。
