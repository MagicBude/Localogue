# Maker / Label / Series 详情页

V1-02 的分类索引页直接把用户送到 `/works?...`。

V1-03 开始，Maker、Label、Series 成为真正可浏览的资料实体：

```text
分类索引
→ 实体详情
→ 相关作品
→ 完整筛选结果
```

## Maker 详情

展示：

- 日 / 中 / 英名称；
- 简介；
- 旗下 Label；
- 相关作品预览；
- 进入完整 Maker 筛选结果。

## Label 详情

展示：

- 日 / 中 / 英名称；
- 所属 Maker；
- 相关作品；
- 返回 Maker 的反向关系。

## Series 详情

展示：

- 日 / 中 / 英名称；
- 系列简介；
- 系列作品预览；
- 进入完整系列作品结果。

这体现了 Localogue 的重要原则：**关系不仅用于筛选，也必须能够被浏览和反向导航。**
