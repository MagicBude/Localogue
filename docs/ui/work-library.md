# 作品库页面

## 视图

长期支持：

1. 海报墙；
2. 列表；
3. 紧凑表格。

V1 优先海报墙 + 列表。

## 筛选栏

至少提供：

- 人物；
- 导演；
- Maker；
- Label；
- Series；
- 时间；
- 时长；
- Work Type；
- Genre；
- Tag；
- 文件 / 封面 / 完整度。

## 作品卡

建议显示：

- 主封面；
- 番号；
- 当前语言标题；
- 发行日期；
- 主演人物；
- 时长；
- Work Type 标记；
- 是否有本地文件。

## V1-02：三种作品视图

作品库支持：

1. 海报墙：默认视图，强调封面和浏览感；
2. 列表：同时展示缩略图、标题、演员、日期、时长、Maker；
3. 表格：适合资料核对和高密度浏览。

视图使用 URL 参数 `view=grid|list|table`，并与筛选、排序条件共同保存在 URL 中。

## V1-03 实现补充

- 左侧筛选栏桌面宽度调整为约 320~350px，并修复 Grid 子项固有宽度导致的横向滚动；
- 当前筛选条件在结果区顶部显示为 Chips；
- 点击 Chip 只移除对应条件，并将分页重置到第 1 页；
- 作品结果使用 URL 分页；
- Grid / List / Table 切换保持当前滚动位置；
- 翻页则使用 `#work-results` 返回结果区顶部。
