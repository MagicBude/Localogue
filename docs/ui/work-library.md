# 作品库页面

## 视图

长期支持：

1. 海报墙；
2. 列表；
3. 紧凑表格。

V1 优先海报墙 + 列表。

## 筛选栏

至少提供：

- 人物；
- 导演；
- Maker；
- Label；
- Series；
- 时间；
- 时长；
- Work Type；
- Genre；
- Tag；
- 文件 / 封面 / 完整度。

## 作品卡

建议显示：

- 主封面；
- 番号；
- 当前语言标题；
- 发行日期；
- 主演人物；
- 时长；
- Work Type 标记；
- 是否有本地文件。

## V1-02：三种作品视图

作品库支持：

1. 海报墙：默认视图，强调封面和浏览感；
2. 列表：同时展示缩略图、标题、演员、日期、时长、Maker；
3. 表格：适合资料核对和高密度浏览。

视图使用 URL 参数 `view=grid|list|table`，并与筛选、排序条件共同保存在 URL 中。

## V1-03 实现补充

- 左侧筛选栏桌面宽度调整为约 320~350px，并修复 Grid 子项固有宽度导致的横向滚动；
- 当前筛选条件在结果区顶部显示为 Chips；
- 点击 Chip 只移除对应条件，并将分页重置到第 1 页；
- 作品结果使用 URL 分页；
- Grid / List / Table 切换保持当前滚动位置；
- 翻页则使用 `#work-results` 返回结果区顶部。

## Desktop 媒体优先密度

作品库首屏优先展示封面和结果，不为页面标题、说明文字和筛选容器预留大块装饰空间：

- 顶部应用栏和页面身份区使用紧凑高度；
- 筛选工具栏保留常用入口，低频条件继续进入弹层；
- 海报墙网格使用更小的最小卡片宽度和间距，让可用宽度优先回到图片；
- 作品卡片仍保留番号、标题、日期、人物和分类，信息通过行数限制收口，不删除可操作内容。

人物库复用相同的壳层密度和网格间距，避免作品与人物页面出现两套视觉节奏。

## Desktop 窗口级搜索与结果底栏

- 全局作品搜索位于窗口级顶部栏，不再占用作品内容区的标题高度；
- 作品与人物的分页、页码跳转和每页数量统一放在结果框底部的独立底栏，不随中间结果内容滚动；
- 只有一页时隐藏左侧翻页、页码和跳转，右侧“每页显示”继续保留；
- 页码变化仍回到结果区开头，页数和每页数量变化都会重置到第 1 页；
- 瀑布流继续使用加载更多，不显示与连续流冲突的页码底栏。

## Desktop 窗口框架

- Tauri 使用自绘无边框标题栏，搜索框位于窗口最上方并保持跨页面可用；
- 搜索框以整个窗口为基准居中并限制宽度，不受左右工具数量影响；
- 标题栏保留最小化、最大化和关闭操作，空白区域通过显式 Tauri Window 权限拖动窗口；
- 影片库采用明确的分区骨架：筛选工具区、结果标题区、独立滚动的图片结果区和分页底栏分别占据自己的布局区域；
- 筛选与底栏不再使用覆盖作品卡片或侧栏的窗口级悬浮定位，各区通过边框和背景形成稳定边界；
- 结果底栏只属于右侧内容框，人物与作品复用同一结构，避免滚动到页面末尾时分页位置跳动或遮挡卡片。
