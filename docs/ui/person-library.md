# 人物库

V1 重点优化演员浏览，同时保留 Person 通用模型。

## 卡片信息

- 主头像；
- 日文正式名；
- 当前语言名称；
- 当前状态；
- 出道时间；
- 作品数量。

## 筛选

- 在役 / 引退 / 休止 / 未知；
- 出道年份；
- 出生年份；
- 是否有头像；
- 作品数量；
- 资料完整度。

## 搜索

搜索必须覆盖：正式名、中文映射、罗马字、旧艺名、别名、曾用名。

## V1-03 实现补充

人物库第一批高级筛选包括：

- 所有姓名类型搜索：正式名、本地化名称、罗马字、别名、旧艺名、曾用名和其他写法；
- 当前活动状态；
- 出生年份；
- 出道年份；
- 引退年份；
- 身高最小值 / 最大值；
- 姓名、出生时间、出道时间、身高排序；
- URL 分页。

职业年份来自 `careerEvents`，不会额外复制成互相可能不一致的简单字段。

## Desktop 当前交互

人物页与作品页使用同一套顶部筛选骨架：

- 常用条件固定在顶部工具栏：姓名 / 别名搜索、活动状态和排序；
- 出道、引退、出生年份及身高范围收进“更多”小弹层，不再占用结果区高度；
- 已选条件在结果数量上方显示为可单独移除的 Chips；
- 分页与清除位于结果行，翻页不会要求用户回到页面最上方；
- 窄窗口允许工具栏自然换行，不使用页面级横向滚动遮盖控件。

筛选条件仍由共享 `queryPeople` 语义执行，UI 的收纳方式不会改变查询、分页或人物姓名全量匹配规则。
