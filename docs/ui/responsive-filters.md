# 响应式筛选器设计

Localogue 的筛选条件很多，因此筛选器既要信息密度高，又不能因为控件过窄出现横向滚动。

## 桌面端

- 作品与人物页面都使用结果区上方的顶部筛选工具栏；
- 常用条件常驻，低频条件通过锚点弹层渐进展开；
- 已选条件在结果区显示为可移除 Chips，结果数量、分页和清除保持同一行；
- 弹层只允许自身纵向滚动，不覆盖页面级结果结构；
- 长选项文字允许换行，控件本身不制造页面横向滚动。

## 中小屏幕

当页面宽度低于约 860px：

- 筛选栏移到作品列表上方；
- sticky 取消；
- 日期、时长双列改为单列；
- 顶部常用条件自然换行，弹层条件改为单列或双列；
- 不再出现页面级横向滚动。

## 原则

不要通过 `overflow-x: hidden` 粗暴掩盖所有问题。

真正要先解决的是 Grid/Flex 子项的最小宽度：

```css
min-width: 0;
grid-template-columns: minmax(0, 1fr);
```

只有在确认内容可以合理收缩后，才限制筛选容器不出现横向滚动。
