# 人物详情页

人物详情页是 Localogue 的重点页面，不应只是简单 CRUD 表单。

## 视觉区域

- 大尺寸人物头像；
- 日文正式名作为主标题；
- 中文映射；
- 英文 / 罗马字；
- 当前状态徽标；
- 出生日期与出生地；
- 身高；
- B / W / H / Cup；
- 出道日期；
- 引退日期（如果存在）；
- 复出 / 休止等事件；
- 三语简介。

## 名称区域

分组展示：

- 正式名；
- 中文名；
- Romanized；
- 艺名；
- 旧艺名 / 曾用名；
- 别名；
- 其他写法。

必要时展示各名称有效时间和来源。

## 职业时间线

用时间线展示出道、改名、休止、引退、复出等事件。

## 作品区域

展示人物全部作品，并复用全局 WorkQuery：

- 年份；
- 月份；
- Maker；
- Label；
- Series；
- Work Type；
- Genre；
- Tag；
- 时长；
- 本地文件状态；
- 排序。

## 统计

可显示：

- 总作品数；
- 各年份数量；
- 各 Work Type 数量；
- 常见 Maker；
- 常见 Series。
