# 导入审核 UI

## 导入首页

入口：

- 扫描文件夹；
- 上传 NFO；
- 上传 JSON；
- 粘贴 JSON；
- CSV；
- XLSX；
- 手工录入。

## 批次页

显示：

- 批次来源；
- 项目数量；
- 可直接确认数量；
- 冲突数量；
- 疑似重复；
- 新人物；
- 未映射词汇；
- 错误。

## 对比页

推荐采用三列或双列差异：

```text
字段       当前资料        本次导入
标题       A              B
演员       A              A、B
时长       120            125
```

每个字段可选择保留、采用或合并。
