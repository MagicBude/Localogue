# 文件存储模式

Localogue 区分“资料库数据”和“用户媒体文件”。

## Indexed（索引模式）

V1 默认模式。

Localogue 只记录用户已有文件的位置和基础信息，不移动、不重命名、不复制。

适合：已有硬盘、NAS 或自己整理好的目录。

## Managed（托管模式）

未来可选。

用户明确启用后，由 Localogue 按规则把媒体和旁路文件整理进受管理目录。

因为涉及移动、重命名和冲突处理，V1 不实现。

## Linked（链接模式）

未来可选。

通过硬链接或软链接建立 Localogue 管理视图，同时尽量避免复制大文件。

不同操作系统、文件系统支持情况不同，实现前需要单独 ADR。

## 原则

任何可能破坏用户原始目录的模式都必须显式启用，不能因为扫描或编辑元数据自动触发。
