## 本轮已修改

- 作品/人物详情按实体隔离草稿；加载、失败与记录不存在时仍可返回。
- 标签管理串行执行修改，私人归属只读取一次集合。
- 关于页增加离线中日英教程，明确当前没有在线自动更新能力；长弹窗正文滚动、操作区保留。
- 首页卡片读取完整题材和标签名称，人物/分类入口与作品库一致。
- 收藏和评分读取/保存失败不再静默吞掉错误。
- 普通/成功消息在 4.5 秒周期末尾淡出；相同消息重新触发会重新计时；减少动态效果模式不播放动画。
- 作品编辑候选搜索覆盖人物所有姓名；取消会丢弃未保存字段、关系选择和暂存 Tag，收起仍保留草稿。
- 瀑布流自动预取和手动加载共用同步锁，避免同帧重复请求多批数据。
- 作品浏览返回快照保存 WorkQuery、普通页码或瀑布流批次、视图和滚动位置；返回后重新查询 Repository，再恢复原浏览位置。
- 人物编辑增加取消草稿；人物与作品表单保存期间锁定全部输入和相关操作，并用同步 Ref 阻止同帧重复提交。
- Presentation Preference 更新按 Private Library 共享队列执行“读取最新值 → 合并单字段补丁 → 写回”，收藏、评分、作品首图与人物头像不会再用旧整对象互相覆盖。
- 参考 JavBoss 的常驻导航思路并结合首轮实机反馈，Work / Person 详情只保留右下角悬浮返回；作品与人物共用分页组件，只在吸顶筛选区显示，主动翻页后定位到新结果开头。
- 顶部应用框架移除重复设置和容易与扫描混淆的手动刷新入口；搜索按番号 / 标题进入 Works 查询，紧凑语言菜单继续区分 UI / Metadata Language。当前采用 Tauri 自绘无边框标题栏，窗口控制与拖动区域由 Desktop 壳层统一提供。
- 应用级 `UiConfirmProvider` 替换全部 8 处 `window.confirm`；业务组件继续用线性 await 表达确认结果，原删除引用检查、Commit fingerprint、Snapshot / Restore 和回收站语义不变。
- 参考本地 JavBoss：作品编辑入口从详情底部长表单提升到首屏标题操作区，使用独立宽弹窗按基础信息、简介、关系与分类分组；原 Private Work / Shared Override 保存规则和删除确认链不变。
- 作品筛选默认只保留排序、更多筛选、视图、条件清除和分页的一行工具栏；高级条件使用覆盖式浮层，选择后即时更新，数量徽标和 Chips 在浮层关闭后仍能说明当前条件，避免筛选面板挤走首屏作品。
- 收藏已提升为左侧独立一级入口，资料库顶部和“更多筛选”不再重复出现收藏；普通筛选菜单只保留目录、人物、作品类型/题材/标签，以及年份、时长、评分、本地媒体和清晰度。厂商、厂牌、系列等关系继续从分类浏览、详情反向导航或已有查询状态进入。
- 对照 JavBoss 截图和 `JavGrid` 后，海报墙改为横向封面、等高卡片与有限信息行；标题开头重复番号只在展示层移除，人物/分类超量以 `+N` 表达。当前开发资料库 46 个 Work 没有任何 Asset，番号占位图反映真实缺图状态，后续需单独补齐封面来源。
