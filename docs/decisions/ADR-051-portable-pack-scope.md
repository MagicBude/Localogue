# ADR-051：Portable Pack 只承担资料迁移，不承担视频共享

## 状态

已接受（2026-09-14）。

## 决策

Portable Pack 保留，但不把它描述成“分享视频”功能，并拆成两个明确用途：

- **个人备份包**：备份当前影片库的作品资料、私人修订、收藏、展示偏好、管理图片和历史记录。原始视频、内容目录、本机路径和播放器设置不进入包；恢复到另一台电脑后，用户需要重新配置内容目录并重新扫描本地视频。
- **社区资料包**：发布只读公共作品、人物、分类、三语名称和受控图片资料。它可以在没有本地视频时作为浏览和策展基础，也可以帮助另一台电脑按番号重新匹配本地视频。

Portable Pack 不负责搬运或授权播放媒体文件，也不尝试让接收者直接打开发送者电脑上的视频。视频共享、云盘同步和跨设备播放不属于 Localogue 0.2 范围。

## 0.2 范围

0.2 只要求个人备份的可靠导出、预览冲突、显式导入和失败回滚；社区资料包保留安装和只读校验能力。压缩封装、跨设备自动同步和大包流式传输可以延后。

## 原因

Localogue 的媒体文件属于用户本机，元数据和媒体路径天然不能代表视频本体。把 Portable Pack 做成“视频分享”会制造错误预期；但完全删除它又会失去私人修订迁移、重装恢复和公共策展资料分发这两个实际用途。
