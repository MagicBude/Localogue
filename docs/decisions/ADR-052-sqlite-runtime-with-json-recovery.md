# ADR-052：SQLite 作为运行时主存储，JSON 保留为恢复与交换层

## 状态

已接受（2026-09-14）。

## 决策

Localogue Desktop 的正常运行时以当前影片库的 `local.db` 和已安装社区资料的 `catalog.db` 为主：

- 浏览、筛选、媒体关联、收藏、展示偏好、Evidence 和治理审计在数据库通过零差异门控后读取 SQLite；
- 私人根一旦被数据库覆盖，Repository 不再重复遍历该根的一实体一 JSON；
- 没有 `catalog.db` 的旧社区资料包继续通过 JSON Adapter 读取；
- SQLite 不可用、迁移失败或对账出现差异时，回退到 JSON 读取，并保留失败信息供诊断。

JSON 不再是正常运行时的首选真相来源，但保留为交换、备份、恢复、对账和故障降级格式。SQLite 也不负责保存视频二进制、图片二进制或原始内容目录。

## 原因

“SQLite 唯一运行时存储”不等于“删除所有 JSON”。如果数据库损坏、升级中断或用户需要恢复，删除 JSON 会把可修复故障变成资料丢失。当前用户是单机使用者，优先保证可恢复性比追求形式上的单一文件格式更重要。

## 后续

下一阶段应统一审计事件的 Application / Repository 接口，并为 SQLite 与 JSON 回退共用同一事件语义；不在页面中直接依赖任一物理格式。
