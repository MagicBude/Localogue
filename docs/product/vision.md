# 产品愿景

Localogue 希望成为一个可以长期积累的个人媒体资料馆。

它不以“今天还能不能从某个网站抓到数据”为生存前提，而以用户自己拥有的资料和整理结果为核心资产。即使所有外部站点、API、爬虫都不可用，Localogue 仍然能够完整浏览、搜索、筛选、编辑和导出自己的资料库。

## 两个核心价值

### 资料治理

- 接受不同来源的数据；
- 保留原始证据；
- 规范化字段；
- 识别人、作品、厂商、系列等实体；
- 发现重复和冲突；
- 让用户审核；
- 形成可信的规范资料。

### 资料探索

- 按人物、导演、系列、Maker、Label、时间、Genre、作品类型、Tag、时长等维度浏览；
- 支持多个条件组合；
- 支持排序和时间线；
- 支持从作品反向进入人物、系列、厂商，再继续筛选；
- 人物页不仅是资料卡，而是完整的职业资料与作品探索入口。

## 成功标准

Localogue 成功不是因为“支持了多少网站”，而是因为：

- 数据多年后仍然可理解；
- 用户可以知道某个字段从哪里来；
- 同一人物不会因为多个别名被轻易拆成多个实体；
- 同一作品的多个本地文件不会被误认为多个作品；
- 页面能让用户快速找到“想看的那一类资料”；
- 更换持久化技术时不需要推倒产品层。
