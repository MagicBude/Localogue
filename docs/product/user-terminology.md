# 用户用语规范

本文件规定 Localogue 面向普通用户的中文用语。代码、Schema 和架构文档可以继续使用稳定英文名称，但 UI 不应要求用户先理解实现。

## 五个核心概念

### 影片库

一套相互独立的个人 AV 收藏。每个影片库记住自己的内容目录、作品资料、本地媒体关联、收藏、评分和私人修改。

对应内部概念：`Library Profile + Personal Library`。

不再在普通界面混用：资料库、Library、Profile、私人资料库。

### 内容目录

存放用户原始视频、NFO 和图片的磁盘文件夹。一个影片库可以有多个内容目录，也可以只扫描其中一个。

对应内部概念：`libraryRoots`。

不再使用：资料源目录、Unified Library Root、媒体库目录。

### 社区资料

由 Localogue 社区整理并发布的只读作品、人物、厂商、系列、分类和多语言名称。它帮助显示已有公共事实，不包含用户视频、收藏、评分或私人修改。

对应内部概念：`Curated Catalog / Community Catalog / Shared Pack`。

用户安装的是“社区资料包”；安装后统一称“社区资料”。不再混用公共资料、共享资料、Shared Data。

### 待审核资料

从 NFO、导入文件或未来在线来源取得，但尚未由用户确认采用的资料。审核后才会成为影片库正式显示的内容。

对应内部概念：`Evidence + Review Analysis`。

高级诊断可在括号中显示 Evidence，普通按钮使用“保存为待审核资料”。

### 个人备份

导出当前影片库的个人数据，包括私人修改、收藏、评分、管理图片和审计历史，不包含原始视频。

对应内部概念：`Personal Portable Pack`。

只读社区内容的传输文件称“社区资料包”，不能与个人备份统称为含义不明的“资料包”。

## 动作用语

- **扫描资料库**：检查当前影片库的全部内容目录，依次处理 NFO、图片和视频；
- **扫描此目录**：只处理一个内容目录；
- **检查视频文件**：高级操作，只更新视频存在状态和技术参数；
- **导入**：从用户明确选择的文件或资料包读取内容；
- **审核**：比较待审核资料与现有内容，由用户决定采用哪些字段；
- **应用修改**：把审核决定写入当前影片库；
- **播放**：交给系统关联程序或用户设置的播放器。

“同步”只用于 SQLite/JSON、设备或远端之间确实存在双向/镜像关系的技术说明，不再作为内容目录扫描的普通按钮。

## 只在高级界面或文档出现

- `Canonical`：经过采用、供程序正式显示的结构化资料；
- `Evidence`：不可变来源记录；
- `Commit Plan`：写入前的可重算修改计划；
- `Private Library`：当前影片库的数据存储根；
- `Shared Pack`：社区资料的只读发布容器；
- `Asset`：受管理的图片等资源记录；
- `MediaFile`：本地视频文件记录；
- `Repository`：存储实现抽象。

这些词可以出现在开发者诊断中，但必须同时给出中文含义，不能作为普通用户完成任务的前置知识。

## 分类用语

- `Work Type` → 作品类型；
- `Genre` → 题材；
- `Tag` → 标签；
- `Maker` → 厂商；
- `Label` → 厂牌；
- `Series` → 系列；
- `Presentation Preference` → 显示与收藏设置。

稳定英文 ID 和 Schema 字段不随 UI 文案改变。
