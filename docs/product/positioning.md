# 产品定位

## 一句话定位

**Localogue 是一个本地优先、资料库优先的个人媒体收藏与元数据管理系统。**

## 它是什么

- 结构化资料库；
- 收藏管理器；
- 元数据导入、审核和整理工具；
- 多维浏览与筛选工具；
- NFO / JSON / CSV / XLSX 等格式之间的桥梁；
- 将来可扩展外部 Connector 与 AI 的基础平台。

## 它暂时不是什么

- 不是以在线抓取为核心的刮削器；
- 不是 Jellyfin / Emby 替代品；
- 不是以转码、串流为主的视频服务器；
- 不是云端 SaaS；
- 不是必须联网才能运行的软件；
- 不是把 NFO 当数据库的简单查看器。

## 与刮削器的关系

MDCx、MDC-NG 等工具可以继续负责“取得或整理媒体旁路数据”；Localogue 可以把它们生成的 NFO、图片和文件目录作为输入。

Localogue 不要求用户只能使用某一种采集工具。

## 与媒体服务器的关系

未来可以导出 NFO / 图片给 Jellyfin、Emby、Kodi 使用，也可以记录本地媒体文件路径，但播放器与媒体服务器能力不是 V1 核心。
