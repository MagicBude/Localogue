# 产品范围

## 0.2 必须形成的可用闭环

### 安装与首次使用

- Windows 安装、升级、卸载经过干净环境实机验收；
- 首次启动只要求选择内容目录，私人资料位置提供安全默认值；
- 普通流程不暴露 Evidence、Canonical、Repository 等开发术语；
- 扫描有阶段、数量、当前目录、耗时、错误与取消状态。

### 多目录与媒体识别

- 可添加、编辑、移除和单独扫描任一目录；
- 可选择显示一个、多个或全部目录的作品；
- 增量扫描不重复分析未变化文件；
- 支持 single、multipart、editions、conflict、cross-folder、mixed 和 broken 等已定义案例；
- 未识别文件合法保留，人工确认前不做模糊绑定；
- 默认不移动、不改名、不删除原始媒体。

### 资料库与策展

- Curated Catalog 提供只读公共作品、人物、组织、系列、分类与三语名称；
- Personal Library 保存本地媒体关联、私人修订、收藏、评分、展示偏好和审计历史；
- Source Evidence 保留来源记录，不能直接无条件覆盖整理结果；
- Work 与 MediaFile 分离，同一作品支持无媒体、单文件、多段和不同版本；
- SQLite 用于运行时查询，JSON / CSV 用于交换、审核和恢复。

### 日常体验

- 作品与人物的搜索、筛选、排序、分页和反向导航可用；
- 海报墙、封面墙、瀑布流、列表和表格共享同一查询结果；
- 作品与人物可在首屏附近进入编辑；
- 收藏作为一级入口；
- 界面语言与元数据语言支持日文、简体中文和英文；
- 使用系统关联程序播放，并为用户指定播放器与参数预留安全配置；
- 私人资料能够导出、备份、预览冲突并恢复。

## 0.2 发布门槛

- `pnpm check` 与 Desktop / Rust 边界检查通过；
- Windows 真实大目录的扫描、取消、增量更新与失败恢复完成实机验收；
- 编辑、删除、备份、导入和恢复只使用隔离测试资料库验收；
- 没有会损坏私人资料或阻断启动的已知问题；
- 安装包、版本信息、日志定位和故障说明可供普通用户使用；
- 对是否随 0.2 Stable 提供首个元数据 Adapter 作出正式 ADR 决策。

自动测试通过不等于用户验收完成。Beta 可以先验证纯本地/NFO 闭环；若 Stable 仍要求用户长期依赖另一个软件取得元数据，就不能宣称已经实现完整单一 App 体验。

## 0.2 明确不做

- 通用影视模式与 TMDB 等通用媒体范围；
- CloudDrive2、磁力下载和浏览器下载扩展；
- 内嵌 MPV、视频转码、串流和媒体服务器；
- 云端账号、云同步和多用户权限；
- 未经许可与跨平台验证的第三方二进制打包；
- AI 自动改写 Canonical 数据；
- 自动搬移、重命名或删除用户视频。

## 后续候选

- 一个可替换、可观察、输出 Evidence 的元数据采集 Adapter；
- macOS / Linux 原生桌面发行；
- NAS 的只读或后台索引服务；
- 用户指定播放器的参数模板、播放进度与书签；
- 更多 Provider 的交叉证据与人工冲突处理。

这些候选必须分别评估工程成本、许可、安全边界和真实需求，不因竞品已有就自动进入范围。
