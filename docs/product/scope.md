# 产品范围

## V1 必须具备

### 资料库
- JSON File-backed Canonical Library；
- 作品、人物、导演、Maker、Label、Series、Genre、Tag；
- 作品时长；
- Asset、MediaFile 基础模型；
- Evidence 与 Review 基础模型。

### 浏览
- 作品海报墙、列表、表格至少先完成海报墙和列表；
- 人物列表；
- 高质量人物详情页；
- 从作品进入人物 / 系列 / Maker / Label / Genre；
- 人物详情页内继续筛选作品。

### 筛选
- 演员；
- 导演；
- Maker；
- Label；
- Series；
- 年、月、日期范围；
- 时长；
- Work Type；
- Genre；
- Tag；
- 是否有封面；
- 是否有本地文件；
- 资料完整度。

### 排序
- 发行日期；
- 添加时间；
- 更新时间；
- 番号；
- 标题；
- 时长。

### 人物
- 日文正式名；
- 中文映射；
- 英文 / 罗马字；
- 别名、旧艺名、曾用名、其他写法；
- 当前状态；
- 出道、引退、复出等职业事件；
- 生日、出生地；
- 身高、三围、Cup；
- 三语简介；
- 主头像和其他图片；
- 作品统计与时间线。

### 多语言与主题
- UI：日文、简体中文、英文；
- 元数据显示：支持独立优先级；
- 浅色、深色、跟随系统。

### 导入 / 导出
- Localogue JSON；
- CSV；
- XLSX；
- NFO；
- 文件夹扫描；
- 手工录入；
- Review。

## V1 明确不做

- 在线爬虫；
- 必须联网的 Provider；
- 视频转码；
- 完整播放器；
- 多用户权限；
- 云同步；
- AI Agent；
- Elasticsearch / Meilisearch 等额外搜索服务。
